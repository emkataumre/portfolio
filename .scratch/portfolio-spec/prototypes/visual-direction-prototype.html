I ship large features in old codebases with coding agents, and the reviews pass.

  Now: software engineer at Inact, on a ten-year-old Go and React monorepo. Also part of Solution 8, where the whole team works this way.

Working Method

Plan before code. Every feature starts as a map of decisions. The agent does not write a line until the questions are answered.

Grill the plan. The agent argues against the plan before it builds it. Weak ideas die on paper.

Review in passes. Separate passes for security, dead code, duplication, and error handling. Each one is a fresh context.

Verify at runtime. The agent drives the app, takes screenshots, and queries the database before it says "done".

Tools: Claude Code, custom skills, MCP servers, a wayfinder and grilling flow. Team practice at Solution 8 is written up in the agentic playbook.
